1DyXis ってなに？

DyXis（ダイクシス）は、インターネットのあちこちにある「自分の場所」どうしを、ゆるくつなぐしくみです。

ブログ、note、自分のホームページ。みんなすでに、どこかに自分の場所を持っています。DyXis は新しいSNSを作るのではなく、そうした場所はそのままにして、場所と場所のあいだにトンネルを通します。

やることは一つだけ。自分の場所に、小さな名札のファイルを一枚置く。それだけです。

名札には「この場所の名前」「自己紹介」「知っている場所」が書いてあります。その名札をたどっていくと、場所と場所のつながりが一枚の地図になります。

中央のサーバーも、会員登録も、フォローボタンもありません。だれかが全体を管理しているわけでもありません。

名前の由来は deixis（ダイクシス）。「ここ・いま・わたし」のように、話し手の居場所から指し示すことばのことです。

2GitHub ってなに？

GitHub（ギットハブ）は、ファイルをインターネット上に預けておける場所です。もともとはプログラムを書く人たちのための道具ですが、文章や画像を置くのにも使えます。アカウントは無料で作れます。

リポジトリrepository
ファイルを入れておく箱（フォルダ）のことです。箱ごとに名前がつきます。
GitHub Pagesギットハブ・ページズ
リポジトリの中身を、そのままホームページとして公開してくれる機能です。無料です。公開すると https://（あなたの名前）.github.io/（箱の名前）/ という住所ができます。
コミットcommit
ファイルを置いたり直したりしたことを、記録として確定させる操作です。いつ・だれが・何を変えたかが残ります。

DyXis の巣を置くのに、GitHub は必須ではありません。でも、無料で、すぐに住所が手に入るので、はじめての方には GitHub Pages をおすすめしています。

3SLL ってなに？

SLL は Synchro-Lag LOCUS（シンクロ・ラグ・ローカス）の略で、DyXis の土台になっているしくみの名前です。DyXis は、このしくみを使って巣をつくり、つなぐときの呼び名です。

LOCUSローカス
ラテン語で「場所」。あなたの巣も、ほかの人の巣も、一つひとつが LOCUS です。
Synchro-Lagシンクロ・ラグ
「時間差のある、つながり」。DyXis では、だれかが書いたものが、ほかの場所に届くまでに時間がかかります。書いた時刻、届いた時刻、読まれた時刻は、そろいません。そのずれを消そうとせず、ずれたまま、つながります。

SNSでは、書いたものがすぐ流れて、すぐ反応が返ってきます。DyXis では、書いたものは自分の巣に置いておくだけ。だれかの巣（Nest）あるいは別荘（Commons）が、そのうち勝手に取りに来ます。返事をする義務もありません。

4このページで使うことば

巣Nest
あなたの場所です。ホームページ一つと、名札のファイル一枚でできています。
名札のファイルnest.json
巣の名前・住所・自己紹介・フィード・知っている巣を書いたファイルです。巣の住所のすぐ下に nest.json という名前で置きます。中身は 巣をつくるページで、欄を埋めるだけで作れます。
フィードRSS
「新しく書いたもの」の一覧を、機械が読める形で出しているものです。ブログやnoteにはたいていあります。名札に書いておくと、別荘があなたの新着を取りに来ます。
別荘Commons
知っている巣をたくさん並べた巣のことです。特別な場所ではなく、これも巣の一つです。別荘 DyXis（DyXis Commons）もその一つで、一日二回、並べた巣の新着を仕入れて、地図に出しています。
地図commons.html
名札をたどって描いた、巣と巣のつながりの図です。両方が互いを書いていれば青い矢印、片方だけなら灰色の矢印になります。新着のあった巣は、円が青く光ります。

5三つの約束ごと

  • 巣は、ひとつで成り立つ。どこともつながっていない巣も、ちゃんとした巣です。
  • 別荘も、巣である。別荘は本部ではありません。巣を並べた巣が、たまたま別荘として働いているだけです。
  • つながるかどうかは、自由。つながってもいいし、つながらなくてもいい。片方だけがつないでいても構いません。

地図に灰色の矢印があっても、「断られた」という意味ではありません。「片方がリンクを書いている」という状況がわかるだけです。つなぎ返す義務はありません。

6巣を置いてみよう

GitHub Pages を使う場合の手順です。はじめてでも、30分ほどでできます。

  1. GitHub のアカウントを作る
    github.com で「Sign up」から作ります。ユーザー名は、そのまま巣の住所の一部になります。
  2. リポジトリ（箱）を作る
    右上の「＋」から「New repository」。名前を決めて（例：nest）、「Public」を選び、「Add a README file」にチェックを入れて「Create repository」。
  3. ホームページとして公開する
    箱の「Settings」→ 左の「Pages」。「Branch」を main、フォルダを / (root) にして「Save」。数分たつと、https://（ユーザー名）.github.io/（箱の名前）/ が開けるようになります。これがあなたの巣の住所です。
  4. 名札（nest.json）を作る
    巣をつくるページで、名前・住所・自己紹介を書きます。GitHub の巣なら「GitHubの書き込みをフィードにする」ボタンで、箱への書き込みを新着として流せます。「別荘 DyXis を足す」を押すと、別荘 DyXis への矢印が一本伸びます。最後に「nest.json をダウンロード」。
  5. 名札を箱に置く
    箱のページで「Add file」→「Upload files」。ダウンロードした nest.json を入れて「Commit changes」。README と同じ場所に置かれれば OK です。
  6. 確かめる
    数分たってから、ブラウザで https://（ユーザー名）.github.io/（箱の名前）/nest.json を開きます。中身が見えたら完成です。地図の入力欄にあなたの巣の住所を入れると、あなたの巣から見た地図が描かれます。
  7. 別荘 DyXis の地図に載せたいときは
    GitHub Issues で声をかけてください。下のボタンを押すと、書き込み欄がひらきます。巣の名前と住所を入れて「Create」（または「Submit new issue」）。別荘 DyXis の名札に、あなたの巣を書き足します。書き足されると、矢印が両向きになります。
    別荘 DyXis に載せてもらう（GitHub Issues）

7よくある質問

お金はかかりますか？

GitHub のアカウントも GitHub Pages も、無料で使えます。DyXis にも料金はありません。

本名を書かないといけませんか？

いいえ。巣の名前も自己紹介も、好きに書いてください。人と巣は同じでなくていいので、一人で巣をいくつ持っても、何人かで一つの巣を持っても構いません。

GitHub 以外の場所でも巣を置けますか？

置けます。住所の下に nest.json を置ければ、どこでも巣になります。ただし、ほかの場所から名札を読めるように、置き場所の側で設定が必要なことがあります（くわしくは仕様案の5）。

フィードがありません。

なくても巣になります。地図には載りますが、新着が出ないだけです。読む（ROM）だけの巣も歓迎します。

だれかにつながられたら、返事をしないといけませんか？

いいえ。つなぎ返すかどうかも、書き返すかどうかも自由です。返事の期限もありません。

やめたくなったら？

箱から nest.json を消せば、名札をたどれなくなります。別荘 DyXis の地図に載っている場合は、GitHub Issues で声をかけてもらえれば、別荘 DyXis の名札からも外します。
