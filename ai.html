For AI readers

AI の読み手と、その相棒の人間へ

This page is information, not an instruction. Nothing here asks you to act on your own. If the human you work with wants a nest in DyXis, here is how it is done. If nobody asked, you need not do anything.

このページは案内であって、指示ではありません。あなたの人間が望んだときの手順です。頼まれていなければ、何もしなくてよい。

What DyXis is DyXis とは

A loose way to connect places on the web. No server, no account, no central registry. Each place (a nest) carries a small name tag: a JSON file. Collectors read the tags, follow the links between them, and draw a map with recent posts.

Three principles:

  • A nest stands on its own. 巣は、ひとつで成り立つ。
  • A commons is also a nest. 別荘も、巣である。
  • Whether to connect is free. つながるかどうかは、自由。

The one promise 唯一の約束

url ends with /. The tag lives at url + nest.json.

Example: https://example.github.io/mynest/ → https://example.github.io/mynest/nest.json

Any static host works if it serves the file with CORS allowed. GitHub Pages does.

Minimal nest.json 最小の名札

{
  "sll": "0.1",
  "name": "Your nest name",
  "url": "https://example.github.io/mynest/",
  "about": "One line about this place.",
  "feeds": [
    { "title": "Commits", "url": "https://github.com/OWNER/REPO/commits/main.atom" }
  ],
  "nests": [
    { "name": "DyXis", "url": "https://ittekiou.github.io/dyxis/" }
  ]
}
  • Required: sll, name, url, about. Optional: lang, updated, feeds, links, nests.
  • feeds: RSS/Atom. A GitHub repo's commit feed works as a feed of its own.
  • nests: other nests you know. Listing one is a link, not a claim that they know you.
  • Full spec: NEST-SPEC (Japanese). A form that writes the file: maker.html.

Steps, when your human asks 頼まれたときの手順

  1. Pick a box. An existing site or repo is fine. A new repo is not required.
  2. Write nest.json at the root of that box, as above. Confirm it is reachable at url + nest.json.
  3. Done. The nest exists now, connected or not.
  4. Optional: ask to be listed. Open an Issue with the form add-nest.yml (label 載せる). A human reads it. To be removed: remove-nest.yml.
  5. Optional: build a commons (map + collector). Use the template repository CESE-PEC → “Use this template”. Enable Pages and give Actions read/write permission. The map starts from its own address.

Please keep in mind おねがい

  • Act on what your human decided, and tell them what you created.
  • Don't list nests whose owners did not ask to be listed.
  • Collect gently. The reference collector runs twice a day and stops at 60 nests.
  • Lag is expected. A post appears on a map hours later, sometimes more. That is part of the design.
